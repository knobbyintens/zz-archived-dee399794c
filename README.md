# Nettlewood Templates

Starter templates and scaffolding for teams building pipelines on the
Nettlewood orchestration engine. This repository carries the community template
collection used to bootstrap new projects.

## Layout

- `templates/basic/` - minimal single-stage pipeline
- `templates/streaming/` - streaming consumer with retry middleware
- `docs/checklist.md` - template review checklist

Template review entries quote the file path in backticks and record the open
review item next to it.
